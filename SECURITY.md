# Security policy

Security fixes target the latest released version of Birdwatch.

## Report a vulnerability

Use GitHub’s private vulnerability reporting for this repository. Include the affected version, the impact, and the smallest example that lets the maintainer verify the problem. Use synthetic data and remove write keys, tokens, passwords and visitor identifiers. [Report a vulnerability privately](https://github.com/Jc-hammond/birdwatch/security/advisories/new)

The maintainer will respond in the private advisory, may ask for more details, and will coordinate the fix and disclosure with you there.
